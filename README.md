## Entry

> I finally wrote the bug report I used to hate receiving: three steps, one screenshot, and an admission that I caused it.

## How it works

Run `python3 main.py`. It writes the line above, exactly as written, to `/output/entry.txt` — UTF-8, no trailing newline, no external files, no network. After writing, it reads the file back and exits with an error if the content differs by even one character, is outside 1–240 characters, or ends with a newline.
